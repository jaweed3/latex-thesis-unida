A LaTeX template for UNIDA Gontor thesis and final project proposals, preconfigured for the university's formatting standards, Arabic text, automatic numbering, and BibLaTeX references.

> **Fork:** This is a personal fork of [PPTIK-UNIDA-Gontor/latex-thesis-unida](https://github.com/PPTIK-UNIDA-Gontor/latex-thesis-unida), maintained at **[jaweed3/latex-thesis-unida](https://github.com/jaweed3/latex-thesis-unida)**.

```bash
git clone https://github.com/jaweed3/latex-thesis-unida.git
```

## ✨ Features

- **Format Compliance:** Page layout, margins, and Times New Roman typeface follow the UNIDA Gontor guidelines.
- **Arabic Language Support:** XeLaTeX + `polyglossia` for Qur'anic verses and Arabic text (Amiri font).
- **Document Automation:** Table of Contents, List of Figures, and List of Tables are generated automatically.
- **Reference Management:** `BibLaTeX` with the _Chicago Manual of Style_ (footnotes) citation style.
